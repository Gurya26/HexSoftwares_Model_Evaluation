# Iris Model Evaluation Project

## 📌 Overview
This project evaluates a machine learning model using the Iris dataset.

## 📊 Tasks Performed
- Data preprocessing
- Train-test split
- Model training
- Prediction
- Evaluation using accuracy, confusion matrix, classification report

## 🛠️ Tools
Python, Pandas, Scikit-learn, Seaborn, Matplotlib

## 📈 Results
- High accuracy achieved
- Setosa classified perfectly
- Minor confusion between Versicolor and Virginica
